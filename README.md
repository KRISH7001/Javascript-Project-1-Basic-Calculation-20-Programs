# JavaScript Programming Practice Questions

A collection of 20 beginner-level programs covering variables, data types, type conversion, arithmetic operations, and conditional statements. Each question has its own code file and a screenshot of the output.

## 📁 Project Structure

```
├── q1.ts … q20.js     # Source code for each question
├── q3.html            # HTML page used for question 3
├── output/            # Output screenshots (q1.png … q20.png)
└── README.md
```
